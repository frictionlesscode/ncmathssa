# Quality Gates Implementation Plan (Trust Plan C)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put four automated gates between a content or logic change and a family: an independent answer check for every generator, NC-rule checks over every item, a reviewable answer-key snapshot, and Playwright end-to-end scenarios that also gate the deploy and smoke-test the live site.

**Architecture:** Tests only, plus one `data-testid` hook. A `reference/` folder holds one hand-written solver per generator that reads only what the child sees (prompt, details, option text) and re-derives the key and every tagged distractor with exact rational arithmetic; a pure `checkInstance` runs it over 500 seeds. `ncRules.testkit.ts` encodes each CONFIRMED rule of `nc-rules.md` that text or parameters can decide, as pure functions swept over authored items and 200 instances per generator, and pinned by fixtures so a rule cannot silently stop firing. The answer key is a checked-in one-entry-per-line JSON file regenerated by `npm run answer-key:update`. Playwright drives the production build through eight scenarios on desktop Chromium and mobile WebKit; CI runs them after `verify`, and the deploy workflow smoke-tests the live site.

**Tech Stack:** Vitest 3 (already installed), fast-check (already installed, not needed here), `@playwright/test` 1.63.0 (new devDependency, installed exact), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-30-quality-and-trust-design.md`, section 4 (4.1 to 4.4) in full. Inputs it names as binding: `docs/superpowers/audits/2026-09-30/nc-rules.md` and the audit reports in the same folder. Plans A, B1 and B2 have landed before this one: content and UI copy below are read from the tree as it stood before them, and every place that depends on their result is called out.

## Review Focus

Failure modes the spec implies that are most likely to bite a person using the app, each with the task whose test pins it:

1. A reference solver that agrees with everything (for example one that reads the key off the options) would make the answer checks pass while checking nothing. Pinned in Tasks 2 to 4: every reference must reject the same question with the key moved onto a distractor, and a test forbids reference code from importing any generator code (Task 4).
2. A generator or an authored file added later with no reference solver, or a standard code a rule watches that no longer has items, leaves a gate green over nothing. Pinned by the coverage test (Task 4) and by `has content to check at every standard a rule watches` (Task 5).
3. An NC rule whose regular expression rots (a wording change, a renamed constant) would stop firing without any test noticing. Pinned by one fixture group per rule in `ncRules.test.ts` that holds regardless of the state of the content (Task 5).
4. The answer-key snapshot depending on the order files are discovered in would produce noisy diffs on another machine. Pinned by a reversed-input test (Task 6).
5. Saved data drifting from what the E2E scenarios seed and read (storage key, disclaimer version) would make scenarios 2b and 5 test a state the app no longer reads. Pinned by `e2eConstants.test.ts` (Task 7).
6. The live-site smoke test racing the Pages deploy and going red for a build that is fine. Pinned in Task 12: it polls the site until it answers, retries twice, and runs on the exact commit CI passed.

```ts
/**
 * Exact arithmetic for the answer checks. Deliberately independent of the
 * generators: nothing in this file (or anywhere under `reference/`) imports a
 * template, so a reference solver can never accidentally reuse the code it is
 * supposed to be checking.
 *
 * Numbers are BigInt fractions, so "1/2" and "4/8" are equal by
 * cross-multiplication and "0.1 + 0.2" is exactly "0.3" (no floating point).
 */
export interface Rat {
  n: bigint;
  d: bigint;
}

function gcd(a: bigint, b: bigint): bigint {
  let x = a < 0n ? -a : a;
  let y = b < 0n ? -b : b;
  while (y !== 0n) [x, y] = [y, x % y];
  return x;
}

export function rat(n: number | bigint, d: number | bigint = 1): Rat {
  let num = BigInt(n);
  let den = BigInt(d);
  if (den === 0n) throw new Error('rat: zero denominator');
  if (den < 0n) {
    num = -num;
    den = -den;
  }
  const g = gcd(num, den) || 1n;
  return { n: num / g, d: den / g };
}

export const add = (a: Rat, b: Rat): Rat => rat(a.n * b.d + b.n * a.d, a.d * b.d);
export const sub = (a: Rat, b: Rat): Rat => rat(a.n * b.d - b.n * a.d, a.d * b.d);
export const mul = (a: Rat, b: Rat): Rat => rat(a.n * b.n, a.d * b.d);
export const div = (a: Rat, b: Rat): Rat => rat(a.n * b.d, a.d * b.n);
/** Cross-multiplication: no division, so no rounding. */
export const cmp = (a: Rat, b: Rat): number => {
  const l = a.n * b.d;
  const r = b.n * a.d;
  return l < r ? -1 : l > r ? 1 : 0;
};
export const eq = (a: Rat, b: Rat): boolean => cmp(a, b) === 0;

/** A decimal literal such as "12.05" or "1,204" as an exact fraction. */
export function decimal(text: string): Rat {
  const m = /^(-?)(\d+)(?:\.(\d+))?$/.exec(text.replace(/,/g, '').trim());
  if (!m) throw new Error(`decimal: cannot read "${text}"`);
  const frac = m[3] ?? '';
  const n = BigInt(`${m[2]}${frac}`) * (m[1] === '-' ? -1n : 1n);
  return rat(n, 10n ** BigInt(frac.length));
}

/**
 * "5", "1,204", "0.75", "3/4", "1 3/4", "$1.50", "45¢", "24 stickers",
 * "8 square meters" as a quantity. Anything else (a clock time, "45 R 2", a
 * list, a sentence) is not a single quantity and returns null: those options
 * are compared by text only.
 */
export function quantityOf(raw: string): Rat | null {
  const s = raw.trim().replace(/^\$/, '').replace(/¢$/, '').replace(/(?<=\d),(?=\d{3}\b)/g, '');
  let m = /^(\d+)\s+(\d+)\/(\d+)(?:\s+[A-Za-z][A-Za-z ]*)?$/.exec(s);
  if (m) return add(rat(BigInt(m[1])), rat(BigInt(m[2]), BigInt(m[3])));
  m = /^(\d+)\/(\d+)(?:\s+[A-Za-z][A-Za-z ]*)?$/.exec(s);
  if (m) return rat(BigInt(m[1]), BigInt(m[2]));
  m = /^(\d+(?:\.\d+)?)(?:\s+[A-Za-z][A-Za-z ]*)?$/.exec(s);
  if (m) return decimal(m[1]);
  return null;
}

/** Exact decimal text with the given number of places, e.g. fixed(rat(1305,100), 2) = "13.05". */
export function fixed(r: Rat, places: number): string {
  const scale = 10n ** BigInt(places);
  const scaled = r.n * scale;
  if (scaled % r.d !== 0n) throw new Error(`fixed: ${r.n}/${r.d} needs more than ${places} places`);
  const v = scaled / r.d;
  const neg = v < 0n;
  const digits = (neg ? -v : v).toString().padStart(places + 1, '0');
  const cut = digits.length - places;
  const body = places === 0 ? digits : `${digits.slice(0, cut)}.${digits.slice(cut)}`;
  return neg ? `-${body}` : body;
}

/** Shortest exact decimal (trailing zeros removed), up to `maxPlaces` places. */
export function trimmed(r: Rat, maxPlaces = 6): string {
  for (let p = 0; p <= maxPlaces; p++) {
    const scale = 10n ** BigInt(p);
    if ((r.n * scale) % r.d === 0n) return fixed(r, p);
  }
  throw new Error(`trimmed: ${r.n}/${r.d} is not a short decimal`);
}
```

```ts
import type { GeneratedQuestion } from '../../engine/template';

/** What a distractor tagged with a misconception may legitimately read. A list
 *  of exact option texts, or a predicate when the tag names a shape of wrong
 *  answer rather than one value (e.g. "the option that compares by digit
 *  count"). */
export type WrongSpec = string[] | ((optionText: string) => boolean);

export interface Expectation {
  /** The one correct option text; two spellings when the generator randomly
   *  words the same true sentence two ways ("47 > 38" or "38 < 47"). */
  answer: string | string[];
  /** misconception tag -> what an option carrying that tag may read. A tag
   *  with no entry here is a defect: the checker cannot vouch for it. */
  wrong: Record<string, WrongSpec>;
}

/** A per-template reference solver. It receives only what the child sees
 *  (prompt, promptDetails, option texts) and re-derives the answer from that,
 *  in code that shares nothing with the generator. */
export type Reference = (g: GeneratedQuestion) => Expectation;
```

```ts
import type { GeneratedQuestion } from '../../engine/template';
import { cmp, quantityOf } from './rational';
import type { Reference, WrongSpec } from './types';

/** Text that reached a child with a template or arithmetic failure showing. */
const CORRUPTION = /\bNaN\b|\bInfinity\b|\bundefined\b|\bnull\b|\[object \w+\]|\$\{|\{\{|\}\}/;

/** Compares option texts ignoring spacing and thousands separators, so "1,204" and
 *  "1204" are the same answer; a formatting choice is not a correctness question. */
export const normalise = (t: string): string =>
  t.trim().replace(/(?<=\d),(?=\d{3}\b)/g, '').replace(/\s+/g, ' ');

function matches(spec: WrongSpec, text: string): boolean {
  return typeof spec === 'function' ? spec(text) : spec.some((x) => normalise(x) === normalise(text));
}
const describe = (spec: WrongSpec): string =>
  typeof spec === 'function' ? 'a text matching that misconception\'s shape' : spec.join(' or ');

/** Every string a child (or a parent reading the explanation) can see. */
export function visibleText(g: GeneratedQuestion): string[] {
  return [
    g.prompt,
    g.promptDetails ?? '',
    ...g.options.map((o) => o.text),
    ...g.explanation.stepByStep,
    g.explanation.conceptSummary,
    g.explanation.commonMisconception ?? '',
  ];
}

/**
 * Checks one generated question against its reference solver. Returns the
 * problems found, empty when the question is sound. Pure (no test framework),
 * so the test file can also feed it deliberately broken questions to prove the
 * checks bite.
 */
export function checkInstance(g: GeneratedQuestion, ref: Reference): string[] {
  const problems: string[] = [];

  const correct = g.options.filter((o) => o.isCorrect);
  if (correct.length !== 1) {
    return [`${correct.length} options are marked correct, expected exactly 1`];
  }
  if (g.options.length !== 4) problems.push(`${g.options.length} options, expected 4`);
  if (g.answerText !== correct[0].text) {
    problems.push(`answerText "${g.answerText}" is not the marked option "${correct[0].text}"`);
  }

  const texts = g.options.map((o) => normalise(o.text));
  if (new Set(texts).size !== texts.length) problems.push(`option texts repeat: ${texts.join(' | ')}`);

  // Distinct text is not distinct answers: 1/2 and 2/4 are one answer written twice.
  for (let i = 0; i < g.options.length; i++) {
    for (let j = i + 1; j < g.options.length; j++) {
      const a = quantityOf(g.options[i].text);
      const b = quantityOf(g.options[j].text);
      if (a && b && cmp(a, b) === 0) {
        problems.push(`options ${g.options[i].label} "${g.options[i].text}" and ${g.options[j].label} "${g.options[j].text}" are the same quantity`);
      }
    }
  }

  for (const text of visibleText(g)) {
    const bad = CORRUPTION.exec(text);
    if (bad) problems.push(`"${bad[0]}" appears in: ${text.slice(0, 120)}`);
  }

  let expected;
  try {
    expected = ref(g);
  } catch (e) {
    problems.push(`the reference solver could not solve it: ${(e as Error).message}`);
    return problems;
  }

  const acceptable = [expected.answer].flat();
  if (!acceptable.some((a) => normalise(a) === normalise(correct[0].text))) {
    problems.push(`marked answer "${correct[0].text}" but the reference solver gets ${acceptable.join(' or ')}`);
  }

  for (const o of g.options) {
    if (o.isCorrect) continue;
    if (!o.misconception) {
      problems.push(`option ${o.label} "${o.text}" has no misconception tag`);
      continue;
    }
    const spec = expected.wrong[o.misconception];
    if (!spec) {
      problems.push(`option ${o.label} "${o.text}" is tagged "${o.misconception}", which the reference solver has no rule for`);
    } else if (!matches(spec, o.text)) {
      problems.push(`option ${o.label} is tagged "${o.misconception}" but reads "${o.text}"; that misconception gives ${describe(spec)}`);
    }
  }
  return problems;
}
```

```ts
import type { Rat } from './rational';

/** A regex match or a loud failure: a reference that cannot read its own
 *  template's prompt must fail the test, never quietly skip it. */
export function grab(re: RegExp, s: string, what: string): RegExpExecArray {
  const m = re.exec(s);
  if (!m) throw new Error(`reference could not read ${what} in: ${JSON.stringify(s)}`);
  return m;
}

/** Every whole number in the text, thousands separators removed. */
export function ints(s: string): number[] {
  return (s.match(/\d[\d,]*/g) ?? []).map((t) => Number(t.replace(/,/g, '')));
}

export const plural = (n: number, word: string): string => `${n} ${word}${n === 1 ? '' : 's'}`;
export const commas = (n: number): string => `${n}`.replace(/\B(?=(\d{3})+(?!\d))/g, ',');
export const pad2 = (n: number): string => (n < 10 ? `0${n}` : `${n}`);
/** Digits of n, least significant first: 4,073 -> [3, 7, 0, 4]. */
export const digitsOf = (n: number): number[] => `${n}`.split('').reverse().map(Number);
const fromDigits = (ds: number[]): number => ds.reduce((acc, d, i) => acc + d * 10 ** i, 0);

/** "3/4", or "3" when the fraction is a whole number. Never a mixed number. */
export function fractionText(r: Rat): string {
  return r.d === 1n ? `${r.n}` : `${r.n}/${r.d}`;
}

/** A whole number of 1/d parts written as a mixed number over the SAME denominator
 *  (no simplifying): 14 parts of 1/12 is "1 2/12". */
export function mixedOver(parts: number, d: number): string {
  const whole = Math.floor(parts / d);
  const rem = parts % d;
  if (rem === 0) return `${whole}`;
  return whole === 0 ? `${rem}/${d}` : `${whole} ${rem}/${d}`;
}

// ---- Column arithmetic done wrong on purpose, from the definition of the error.

/** The ten made in the ones column is never carried: the sum minus every ten the
 *  ones digits made. (Later columns still carry; that is what the shipped
 *  explanations mean by "forgot the carry".) */
export function dropOnesCarry(addends: number[]): number {
  const sum = addends.reduce((x, y) => x + y, 0);
  const onesTotal = addends.reduce((x, y) => x + (y % 10), 0);
  return sum - 10 * Math.floor(onesTotal / 10);
}

/** That carried ten written in the hundreds column instead of the tens. */
export function carryIntoWrongColumn(addends: number[]): number {
  const onesTotal = addends.reduce((x, y) => x + (y % 10), 0);
  return dropOnesCarry(addends) + 100 * Math.floor(onesTotal / 10);
}

/** Every column added on its own, no carry anywhere (digit sums mod 10). */
export function addNoCarry(a: number, b: number): number {
  const x = digitsOf(a);
  const y = digitsOf(b);
  const len = Math.max(x.length, y.length);
  return fromDigits(Array.from({ length: len }, (_, i) => ((x[i] ?? 0) + (y[i] ?? 0)) % 10));
}

/** Each column's smaller digit taken from its larger, whichever is on top. */
export function subtractColumnsBackwards(a: number, b: number): number {
  const x = digitsOf(a);
  const y = digitsOf(b);
  const len = Math.max(x.length, y.length);
  return fromDigits(Array.from({ length: len }, (_, i) => Math.abs((x[i] ?? 0) - (y[i] ?? 0))));
}

/** A ten borrowed into the ones column but never taken from the tens. */
export function borrowNeverPaid(a: number, b: number): number {
  const x = digitsOf(a);
  const y = digitsOf(b);
  const len = Math.max(x.length, y.length);
  return fromDigits(
    Array.from({ length: len }, (_, i) => (i === 0 ? (x[0] ?? 0) + 10 : (x[i] ?? 0)) - (y[i] ?? 0)),
  );
}

/** Solves an equation with a single ☐ by trying every whole number. Independent
 *  of how the generator built the equation: it just evaluates both sides. */
export function solveBox(equation: string, max = 60): number {
  const side = (s: string, x: number): number => {
    const t = s.replace('☐', String(x)).trim();
    const m = /^(\d+)(?:\s*([+−])\s*(\d+))?$/.exec(t);
    if (!m) throw new Error(`solveBox: cannot evaluate "${s}"`);
    const a = Number(m[1]);
    if (!m[2]) return a;
    return m[2] === '+' ? a + Number(m[3]) : a - Number(m[3]);
  };
  const [left, right] = equation.split('=');
  const hits: number[] = [];
  for (let x = 0; x <= max; x++) if (side(left, x) === side(right, x)) hits.push(x);
  if (hits.length !== 1) throw new Error(`solveBox: "${equation}" has ${hits.length} solutions`);
  return hits[0];
}
```

```ts
/** "3/4 > 3/8", "3/8 < 3/4", "1/2 = 2/4" -> its parts, or null for any other text. */
function statement(text: string): { l: [number, number]; op: string; r: [number, number] } | null {
  const m = /^(\d+)\/(\d+) ([<>=]) (\d+)\/(\d+)$/.exec(text.trim());
  if (!m) return null;
  return { l: [Number(m[1]), Number(m[2])], op: m[3], r: [Number(m[4]), Number(m[5])] };
}
function isTrue(st: NonNullable<ReturnType<typeof statement>>): boolean {
  const c = cmp(rat(st.l[0], st.l[1]), rat(st.r[0], st.r[1]));
  return st.op === '<' ? c < 0 : st.op === '>' ? c > 0 : c === 0;
}
/** The fraction the statement claims is the greater one, or null for '='. */

  return st.op === '>' ? st.l : st.op === '<' ? st.r : null;
}
function claimedLess(st: NonNullable<ReturnType<typeof statement>>): [number, number] | null {
  return st.op === '>' ? st.r : st.op === '<' ? st.l : null;
```

```ts
  if (Array.isArray(value)) return value.flatMap(stringsIn);
  if (value && typeof value === 'object') return Object.values(value).flatMap(stringsIn);
  return [];
}

/** Groups repeated violations so a generator that breaks a rule on 90 of 200
 *  draws produces three lines, not ninety. */
function summarise(found: { id: string; problem: string }[]): string[] {
  const seen = new Map<string, { count: number; example: string }>();
  for (const { id, problem } of found) {
    const rule = problem.split(':')[0];
    const key = `${id.split('#')[0]} ${rule}`;
    const prev = seen.get(key);
    if (prev) prev.count += 1;
    else seen.set(key, { count: 1, example: `${id} ${problem}` });
  }
  return [...seen.values()].map((v) => `${v.example}${v.count > 1 ? `  (and ${v.count - 1} more like it)` : ''}`);
}
```

```ts
import type { Question } from '../engine/questionModel';
import type { GeneratedQuestion, QuestionTemplate } from '../engine/template';

/**
 * The confirmed NC rules from docs/superpowers/audits/2026-09-30/nc-rules.md that
 * can be decided from the text a child sees. One `NcRule` per rule id, each a
 * pure function of a `RuleItem`, so the same code sweeps authored questions and
 * generated instances and can be pinned by fixtures without touching content.
 *
 * Reading a rule below: the comment names the row of nc-rules.md, and the check
 * decides only what the text lets it decide. A rule the text cannot decide
 * (for example "one conversion step" written as a word problem) is NOT encoded
 * here as a weaker guess; it stays a review item in the plan that owns it.
 */
export interface RuleOption {
  label: string;
  text: string;
  isCorrect: boolean;
  misconception?: string;
}

export interface RuleItem {
  /** Question id, or `${templateId}#${seed}` for a generated instance. */
  id: string;
  grade: number;
  standardCode: string;
  prompt: string;
  promptDetails: string;
  options: RuleOption[];
  /** stepByStep + conceptSummary: what the item TEACHES. */
  explanation: string[];
  /** commonMisconception: describes an error, so it may quote wrong claims. */
  misconceptionNote: string;
}

export interface NcRule {
  id: string;
  summary: string;
  check(item: RuleItem): string[];
}

const gradeOf = (standardCode: string): number => Number(/^NC\.(\d)\./.exec(standardCode)?.[1] ?? 0);

export function itemFromAuthored(q: Question): RuleItem {
  return {
    id: q.id,
    grade: gradeOf(q.standardCode),
    standardCode: q.standardCode,
    prompt: q.prompt,
    promptDetails: q.promptDetails ?? '',
    options: q.options.map((o) => ({ label: o.label, text: o.text, isCorrect: o.isCorrect, misconception: o.misconception })),
    explanation: [...q.explanation.stepByStep, q.explanation.conceptSummary],
    misconceptionNote: q.explanation.commonMisconception ?? '',
  };
}

export function itemFromGenerated(t: QuestionTemplate, g: GeneratedQuestion, seed: number): RuleItem {
  return {
    id: `${t.id}#${seed}`,
    grade: gradeOf(t.standardCode),
    standardCode: t.standardCode,
    prompt: g.prompt,
    promptDetails: g.promptDetails ?? '',
    options: g.options.map((o) => ({ label: o.label, text: o.text, isCorrect: o.isCorrect, misconception: o.misconception })),
    explanation: [...g.explanation.stepByStep, g.explanation.conceptSummary],
    misconceptionNote: g.explanation.commonMisconception ?? '',
  };
}

const correctText = (i: RuleItem): string => i.options.find((o) => o.isCorrect)?.text ?? '';
/** Everything shown, including distractors and the worked solution. */
const everything = (i: RuleItem): string =>
  [i.prompt, i.promptDetails, ...i.options.map((o) => o.text), ...i.explanation, i.misconceptionNote].join('\n');

const num = (t: string): number => Number(t.replace(/,/g, ''));
const digitCount = (t: string): number => t.replace(/[^\d]/g, '').length;
const places = (t: string): number => (t.split('.')[1] ?? '').length;

const NUMBER = String.raw`\d[\d,]*(?:\.\d+)?|\.\d+`;
const FRACTION_OR_WHOLE = String.raw`(?:\d+ )?\d+\/\d+|\d[\d,]*(?:\.\d+)?`;

/** Every `A op B` in the text, with the operator one of the given symbols. */
function binary(text: string, ops: string): { a: string; b: string }[] {
  const re = new RegExp(`(${FRACTION_OR_WHOLE})\\s*[${ops}]\\s*(${FRACTION_OR_WHOLE})`, 'g');
  return [...text.matchAll(re)].map((m) => ({ a: m[1], b: m[2] }));
}
const isFraction = (t: string): boolean => t.includes('/');
const denominatorOf = (t: string): number => Number(t.split('/')[1]);
const numeratorOf = (t: string): number => Number(t.split('/')[0].trim().split(' ').pop());

const inFamily = (families: number[][], a: number, b: number): boolean =>
  a === b || families.some((f) => f.includes(a) && f.includes(b));

/** NC-R1 (5, OA.2): parentheses only; at most two operations per expression. */
const R1: NcRule = {
  id: 'NC-R1',
  summary: 'Grade 5: parentheses only, and at most two operations in an expression',
  check(i) {
    if (i.grade !== 5) return [];
    const out: string[] = [];
    const bracket = /[[\]{}]/.exec(everything(i));
    if (bracket) out.push(`uses "${bracket[0]}"; NC grade 5 grouping is parentheses only`);
    if (i.standardCode === 'NC.5.OA.2') {
      const shown = [i.prompt, i.promptDetails, ...i.options.map((o) => o.text)];
      for (const text of shown) {
        for (const run of text.match(/[\d(][\d\s.,()+\-−×÷*/]*[\d)]/g) ?? []) {
          // A spaced "/" divides; "3/4" is a fraction. A "-" between numbers subtracts.
          const ops = (run.match(/[+×÷*]|(?<=[\d)]\s*)[-−](?=\s*[\d(])|\s\/\s/g) ?? []).length;
          if (ops > 2) out.push(`"${run.trim()}" has ${ops} operations; NC allows two`);
        }
      }
    }
    return out;
  },
};

/** The claims below are what a wrong shape-classification answer says; the
 *  sentence-level exemptions keep a correct explanation that QUOTES the claim
 *  in order to reject it from being flagged. */
const CONTRAST = /\b(not|never|no|false|isn't|aren't|cannot|can't|but|however|although|some books|other books|many books|another|instead|rather|says?|claims?|statement)\b|n't/i;
const sentencesOf = (t: string): string[] => t.split(/(?<=[.!?])\s+/);

/** NC-R2 (1-5): a trapezoid has EXACTLY one pair of parallel sides. */
export function trapezoidProblems(text: string): string[] {
  const out: string[] = [];
  for (const sentence of sentencesOf(text)) {
    if (!/trapezoid/i.test(sentence) || CONTRAST.test(sentence)) continue;
    if (/at least one pair/i.test(sentence)) {
      out.push(`states the inclusive trapezoid definition: "${sentence.trim().slice(0, 140)}"`);
    }
    const claim =
      /\b(squares?|rectangles?|rhombus(?:es)?|rhombi|parallelograms?)\b[^.?!]{0,60}\b(?:is|are)\b\s+(?:always\s+|also\s+|sometimes\s+)?(?:an?\s+)?trapezoids?/i.test(sentence) ||
      /trapezoids?[^.?!]{0,40}\b(?:include|includes|contain|contains)\b[^.?!]{0,30}(?:parallelogram|rectangle|square|rhombus)/i.test(sentence);
    if (claim) out.push(`says a parallelogram, rectangle, rhombus or square is a trapezoid: "${sentence.trim().slice(0, 140)}"`);
  }
  return out;
}

const R2: NcRule = {
  id: 'NC-R2',
  summary: 'A trapezoid has exactly one pair of parallel sides; no parallelogram, rectangle, rhombus or square is one',
  check(i) {
    // Taught text only: the right answer, the worked solution. A wrong option or
    // the "common mistake" note may state the false claim, and the prompt may pose it.
    return [correctText(i), ...i.explanation].flatMap((t) => trapezoidProblems(t));
  },
};

/** NC-R3 (5, NBT.7) and NC-X1 (5, NBT.6): what may be divided by what. */
const R3: NcRule = {
  id: 'NC-R3',
  summary: 'Grade 5 division: whole ÷ decimal or decimal ÷ whole, hundredths, dividends of at most 4 digits',
  check(i) {
    if (i.grade !== 5) return [];
    const out: string[] = [];
    const text = operands(i);
    for (const { a, b } of binary(text, '÷')) {
      if (isFraction(a) || isFraction(b)) continue; // fractions belong to NF.7
      if (i.standardCode === 'NC.5.NBT.7') {
        if (a.includes('.') && b.includes('.')) out.push(`${a} ÷ ${b} divides a decimal by a decimal`);
        if (places(a) > 2 || places(b) > 2) out.push(`${a} ÷ ${b} goes past hundredths`);
        if (digitCount(a) > 4) out.push(`${a} ÷ ${b} has a dividend of more than 4 digits`);
      }
      if (i.standardCode === 'NC.5.NBT.6') {
        if (a.includes('.') || b.includes('.')) out.push(`${a} ÷ ${b} uses a decimal in a whole-number division`);
        if (digitCount(a) > 4) out.push(`${a} ÷ ${b} has a dividend of more than 4 digits`);
        if (digitCount(b) > 2) out.push(`${a} ÷ ${b} has a divisor of more than 2 digits`);
      }
    }
    if (i.standardCode === 'NC.5.NBT.7' || i.standardCode === 'NC.5.NBT.3') {
      for (const t of [operands(i), correctText(i)]) {
        const long = (t.match(/\d*\.\d{4,}/g) ?? [])[0];
        if (long) out.push(`${long} goes past thousandths`);
      }
    }
    return out;
  },
};

/** NC-X2 (5, NBT.5): up to three-digit by two-digit. */
const X2: NcRule = {
  id: 'NC-X2',
  summary: 'Grade 5 multiplication: at most three-digit by two-digit',
  check(i) {
    if (i.standardCode !== 'NC.5.NBT.5') return [];
    return binary(operands(i), '×')
      .filter(({ a, b }) => !isFraction(a) && !isFraction(b) && !(digitCount(a) <= 3 && digitCount(b) <= 2))
      .map(({ a, b }) => `${a} × ${b} is beyond three-digit by two-digit`);
  },
};

/** NC-R4 (5, NBT.1): × 1,000 / 100 / 10 / 0.1 / 0.01 and ÷ 10 / 100 only; no exponents. */
const R4: NcRule = {
  id: 'NC-R4',
  summary: 'Grade 5 powers of ten: × 1,000, 100, 10, 0.1, 0.01 and ÷ 10, 100 only; no exponent notation',
  check(i) {
    if (i.grade !== 5) return [];
    const out: string[] = [];
    const exponent = /10\^|10[²³⁴]|\bexponent/i.exec(everything(i));
    if (exponent) out.push(`uses exponent notation ("${exponent[0]}"); NC grade 5 does not`);
    if (i.standardCode === 'NC.5.NBT.1') {
      const text = `${operands(i)}\n${correctText(i)}`;
      for (const m of text.matchAll(new RegExp(`×\\s*(${NUMBER})`, 'g'))) {
        if (![1000, 100, 10, 0.1, 0.01].includes(num(m[1]))) out.push(`multiplies by ${m[1]}`);
      }
      for (const m of text.matchAll(new RegExp(`÷\\s*(${NUMBER})`, 'g'))) {
        if (![10, 100].includes(num(m[1]))) out.push(`divides by ${m[1]}`);
      }
    }
    return out;
  },
};

const NF1_FAMILIES = [[2, 4, 8], [3, 6, 12], [5, 10, 100]];
/** NC-R6 (5, NF.1): unlike denominators only within a related family. */
const R6: NcRule = {
  id: 'NC-R6',
  summary: 'Grade 5 NF.1: unlike denominators only within {2,4,8}, {3,6,12} or {5,10,100}',
  check(i) {
    if (i.standardCode !== 'NC.5.NF.1') return [];
    return binary(operands(i), '+\\-−')
      .filter(({ a, b }) => isFraction(a) && isFraction(b))
      .filter(({ a, b }) => !inFamily(NF1_FAMILIES, denominatorOf(a), denominatorOf(b)))
      .map(({ a, b }) => `${a} and ${b} have unrelated denominators`);
  },
};

/** NC-R7 (5, NF.4): fraction × fraction uses denominators 2, 3, 4; fraction × whole may use 2-12. */
const R7: NcRule = {
  id: 'NC-R7',
  summary: 'Grade 5 NF.4: fraction × fraction with denominators 2, 3, 4 only',
  check(i) {
    if (i.standardCode !== 'NC.5.NF.4') return [];
    const out: string[] = [];
    const pairs = [
      ...binary(operands(i), '×'),
      ...[...operands(i).matchAll(/(\d+\/\d+) of (\d+\/\d+)/g)].map((m) => ({ a: m[1], b: m[2] })),
    ];
    for (const { a, b } of pairs) {
      if (isFraction(a) && isFraction(b)) {
        for (const d of [denominatorOf(a), denominatorOf(b)]) {
          if (![2, 3, 4].includes(d)) out.push(`${a} × ${b}: a fraction times a fraction may only use denominators 2, 3, 4, not ${d}`);
        }
      } else if (isFraction(a) || isFraction(b)) {
        const d = denominatorOf(isFraction(a) ? a : b);
        if (![2, 3, 4, 5, 6, 8, 10, 12].includes(d)) out.push(`${a} × ${b}: denominator ${d} is not one NC uses`);
      }
    }
    return out;
  },
};

/** NC-R8 (5, NF.7): unit fraction ÷ whole, or whole ÷ unit fraction. */
const R8: NcRule = {
  id: 'NC-R8',
  summary: 'Grade 5 NF.7: one step, unit fraction ÷ whole number or whole number ÷ unit fraction',
  check(i) {
    if (i.standardCode !== 'NC.5.NF.7') return [];
    const out: string[] = [];
    for (const { a, b } of binary(operands(i), '÷')) {
      if (!isFraction(a) && !isFraction(b)) continue;
      if (isFraction(a) && isFraction(b)) out.push(`${a} ÷ ${b} divides a fraction by a fraction (grade 6)`);
      else if (a.includes(' ') || b.includes(' ')) out.push(`${a} ÷ ${b} uses a mixed number`);
      else if (isFraction(a) && numeratorOf(a) !== 1) out.push(`${a} ÷ ${b}: the fraction is not a unit fraction`);
      else if (isFraction(b) && numeratorOf(b) !== 1) out.push(`${a} ÷ ${b}: the divisor is not a unit fraction`);
    }
    return out;
  },
};

  cups: 'customary capacity', pints: 'customary capacity', quarts: 'customary capacity', gallons: 'customary capacity',
  millimeters: 'metric length', centimeters: 'metric length', meters: 'metric length', kilometers: 'metric length',
  milligrams: 'metric mass', grams: 'metric mass', kilograms: 'metric mass',
  milliliters: 'metric capacity', liters: 'metric capacity',
  seconds: 'time', minutes: 'time', hours: 'time', days: 'time', weeks: 'time',
};
/** NC-R9 (5, MD.1): a conversion stays inside one system of measurement. */
const R9: NcRule = {
  id: 'NC-R9',
  summary: 'Grade 5 MD.1: conversions stay within one system (customary, metric or time)',
  check(i) {
    if (i.standardCode !== 'NC.5.MD.1') return [];
    const out: string[] = [];
    for (const m of operands(i).matchAll(/([A-Za-z]+) = \? ([A-Za-z]+)/g)) {
      const [from, to] = [UNIT_SYSTEM[m[1].toLowerCase()], UNIT_SYSTEM[m[2].toLowerCase()]];
      if (!from || !to) out.push(`"${m[1]} = ? ${m[2]}" uses a unit the checker does not know`);
      else if (from !== to) out.push(`converts ${m[1]} (${from}) to ${m[2]} (${to})`);
    }
    return out;
  },
};

const G4_DENOMINATORS = [2, 3, 4, 5, 6, 8, 10, 12, 100];
const denominatorsIn = (t: string): number[] => [...t.matchAll(/\d+\/(\d+)/g)].map((m) => Number(m[1]));
/** NC-R12a (4): fraction denominators; decimal notation uses tenths and hundredths. */
const R12A: NcRule = {
  id: 'NC-R12a',
  summary: 'Grade 4 fractions: denominators 2, 3, 4, 5, 6, 8, 10, 12, 100 (NF.6: 10 and 100)',
  check(i) {
    if (i.grade !== 4) return [];
    const allowed = i.standardCode === 'NC.4.NF.6' ? [10, 100] : G4_DENOMINATORS;
    // A distractor may show the error ("5/110"), so only what is asked and what is right count.
    return denominatorsIn(`${operands(i)}\n${correctText(i)}`)
      .filter((d) => !allowed.includes(d))
      .map((d) => `denominator ${d} is not one NC uses at this standard`);
  },
};

/** NC-R12b (4): whole numbers to 100,000; NBT.5 and NBT.6 shapes. */
const R12B: NcRule = {
  id: 'NC-R12b',
  summary: 'Grade 4 whole numbers up to 100,000; NBT.5 up to 3-digit × 1-digit or 2-digit × 2-digit; NBT.6 up to a 3-digit dividend and a 1-digit divisor',
  check(i) {
    if (i.grade !== 4) return [];
    const out: string[] = [];
    const text = `${operands(i)}\n${correctText(i)}`;
    for (const m of text.matchAll(/(?<![\d./])(\d[\d,]*)(?![\d,]*[./]\d)/g)) {
      if (num(m[1]) > 100000) out.push(`${m[1]} is above 100,000`);
    }
    if (i.standardCode === 'NC.4.NBT.5') {
      for (const { a, b } of binary(operands(i), '×')) {
        const [da, db] = [digitCount(a), digitCount(b)].sort((x, y) => y - x);
        if (!((da <= 3 && db === 1) || (da <= 2 && db <= 2))) out.push(`${a} × ${b} is beyond 3-digit × 1-digit or 2-digit × 2-digit`);
      }
    }
    if (i.standardCode === 'NC.4.NBT.6') {
      for (const { a, b } of binary(operands(i), '÷')) {
        if (digitCount(a) > 3 || digitCount(b) > 1) out.push(`${a} ÷ ${b} is beyond a 3-digit dividend and a 1-digit divisor`);
      }
    }
    return out;
  },
};

const G3_DENOMINATORS = [1, 2, 3, 4, 6, 8];
/**
 * NC-R13a/b (3): denominators 2, 3, 4, 6, 8 (1 for a whole number written as a
 * fraction); a comparison shares a numerator or a denominator.
 *
 * The table also says equivalence and comparison use "related families"
 * ({2,4,8} and {3,6}). That is NOT encoded as "one family per item": the bank
 * legitimately compares 3/4 with 3/6 (same numerator) and writes 3 as 6/2 beside
 * a distractor 2/6. What the text can settle is the list of denominators (no
 * 5, 10, 12 anywhere at NF.3 and NF.4) and the same-numerator-or-denominator rule.
 */
const R13AB: NcRule = {
  id: 'NC-R13a/b',
  summary: 'Grade 3 fractions: denominators 2, 3, 4, 6, 8; a comparison shares a numerator or a denominator',
  check(i) {
    if (i.grade !== 3) return [];
    const out: string[] = [];
    const wholeItem = i.standardCode === 'NC.3.NF.3' || i.standardCode === 'NC.3.NF.4';
    const shown = operands(i);
    const scanned = wholeItem
      ? [shown, ...i.options.map((o) => o.text)].join('\n')
      : [shown, correctText(i)].join('\n');
    for (const d of denominatorsIn(scanned)) {
      if (!G3_DENOMINATORS.includes(d)) out.push(`denominator ${d} is not one NC uses in grade 3`);
    }
    if (i.standardCode === 'NC.3.NF.4') {
      for (const m of [shown, correctText(i)].join('\n').matchAll(/(\d+)\/(\d+)\D{1,25}?(\d+)\/(\d+)/g)) {
        if (m[1] !== m[3] && m[2] !== m[4]) {
          out.push(`${m[1]}/${m[2]} and ${m[3]}/${m[4]} share neither a numerator nor a denominator`);
        }
      }
    }
    return out;
  },
};

/**
 * NC-R13c (3, 4): rounding is not a standard, so no QUESTION asks a child to

const R13C: NcRule = {

  },
};

/** NC-R14 (1): addition within 100 and its neighbours. */
const R14: NcRule = {
  id: 'NC-R14',
  summary: 'Grade 1 NBT: sums within 100; two-digit + one-digit or a multiple of ten; subtract multiples of 10 (10-90); 10 more or less of a two-digit number',
  check(i) {
    if (i.grade !== 1) return [];
    const out: string[] = [];
    if (i.standardCode === 'NC.1.NBT.4') {
      for (const { a, b } of binary(operands(i), '+')) {
        const [x, y] = [num(a), num(b)];
        if (x + y > 100) out.push(`${a} + ${b} is more than 100`);
        if (!(x >= 10 && x <= 99 && ((y >= 1 && y <= 9) || (y >= 10 && y <= 90 && y % 10 === 0)))) {
          out.push(`${a} + ${b} is not two-digit + one-digit or two-digit + a multiple of ten`);
        }
      }
    }
    if (i.standardCode === 'NC.1.NBT.6') {
      for (const { a, b } of binary(operands(i), '−\\-')) {
        for (const t of [a, b]) if (!(num(t) >= 10 && num(t) <= 90 && num(t) % 10 === 0)) out.push(`${t} is not a multiple of 10 from 10 to 90`);
      }
    }
    if (i.standardCode === 'NC.1.NBT.5') {
      const m = /10 (?:more|less) than (\d+)/.exec(i.prompt);
      if (m && !(Number(m[1]) >= 10 && Number(m[1]) <= 99)) out.push(`${m[1]} is not a two-digit number`);
    }
    return out;
  },
};

  2: { maxChars: 220, maxSentences: 6, maxWordLetters: 10, allowlist: ['centimeters', 'rectangular', 'quadrilateral'] },
};

export function detailsReadabilityProblems(item: Pick<RuleItem, 'grade' | 'promptDetails'>): string[] {
  const limit = DETAILS_LIMITS[item.grade];
  const text = item.promptDetails;
  if (!limit || !text) return [];
  const out: string[] = [];
  if (text.length > limit.maxChars) out.push(`promptDetails is ${text.length} characters, at most ${limit.maxChars}`);
  const sentences = text.split(/[.?!]/).filter((s) => s.trim().length > 0).length;
  if (sentences > limit.maxSentences) out.push(`promptDetails has ${sentences} sentences, at most ${limit.maxSentences}`);
  const allowed = new Set(limit.allowlist);
  const long = (text.match(/[A-Za-z]+/g) ?? []).filter((w) => w.length > limit.maxWordLetters && !allowed.has(w.toLowerCase()));
  if (long.length) out.push(`promptDetails uses words longer than ${limit.maxWordLetters} letters: ${long.join(', ')}`);
  return out;
}
```

Design. The file has one entry per line (id or `templateId#seed`, standard, prompt, promptDetails, options as `"A: text"`, marked answer label, `contentVersion`), so a rewritten question is one changed line in the pull request. `contentVersion` is read defensively (`1` when absent), because Plan B adds it to authored questions and does not add it to generators.
```ts
import type { Question } from '../engine/questionModel';
import type { QuestionTemplate } from '../engine/template';
import { makeRng } from '../engine/rng';

/** Spec 4.3: twenty fixed-seed instances of every generator. Seeds 1-20. */
export const ANSWER_KEY_SEEDS = 20;

export interface AnswerKeyEntry {
  /** A question id, or `${templateId}#${seed}` for a generated instance. */
  id: string;
  standard: string;
  prompt: string;
  promptDetails: string;
  options: string[];
  answer: string;
  contentVersion: number;
}

/** Content the plans version: absent means 1, exactly as the spec's default. */
export function contentVersionOf(x: object): number {
  const v = (x as { contentVersion?: unknown }).contentVersion;
  return typeof v === 'number' ? v : 1;
}

function entryOf(
  id: string,
  standard: string,
  prompt: string,
  promptDetails: string | undefined,
  options: { label: string; text: string; isCorrect: boolean }[],
  version: number,
): AnswerKeyEntry {
  return {
    id,
    standard,
    prompt,
    promptDetails: promptDetails ?? '',
    options: options.map((o) => `${o.label}: ${o.text}`),
    answer: options.find((o) => o.isCorrect)?.label ?? '?',
    contentVersion: version,
  };
}

export function buildAnswerKey(authored: Question[], templates: QuestionTemplate[]): {
  authored: AnswerKeyEntry[];
  generated: AnswerKeyEntry[];
} {
  const byId = <T extends { id: string }>(xs: T[]): T[] => [...new Map(xs.map((x) => [x.id, x])).values()];
  return {
    authored: byId(authored)
      .sort((a, b) => a.id.localeCompare(b.id))
      .map((q) => entryOf(q.id, q.standardCode, q.prompt, q.promptDetails, q.options, contentVersionOf(q))),
    generated: byId(templates)
      .sort((a, b) => a.id.localeCompare(b.id))
      .flatMap((t) =>
        Array.from({ length: ANSWER_KEY_SEEDS }, (_, i) => {
          const seed = i + 1;
          const g = t.generate(makeRng(seed));
          return entryOf(`${t.id}#${seed}`, t.standardCode, g.prompt, g.promptDetails, g.options, contentVersionOf(t));
        }),
      ),
  };
}

/** One entry per line, so a content change is a readable line in the pull request diff. */
export function serialiseAnswerKey(key: { authored: AnswerKeyEntry[]; generated: AnswerKeyEntry[] }): string {
  const lines = (xs: AnswerKeyEntry[]) => xs.map((e) => `    ${JSON.stringify(e)}`).join(',\n');
  return `{\n  "authored": [\n${lines(key.authored)}\n  ],\n  "generated": [\n${lines(key.generated)}\n  ]\n}\n`;
}

function entriesOf(text: string): Map<string, string> {
  const out = new Map<string, string>();
  for (const line of text.split('\n')) {
    const trimmed = line.trim().replace(/,$/, '');
    if (!trimmed.startsWith('{"id"')) continue;
    out.set((JSON.parse(trimmed) as AnswerKeyEntry).id, trimmed);
  }
  return out;
}

/** What changed between two serialised answer keys, in words a reviewer can act on. */
export function describeAnswerKeyChange(committed: string, current: string): string[] {
  const before = entriesOf(committed);
  const after = entriesOf(current);
  const out: string[] = [];
  for (const [id, line] of after) {
    if (!before.has(id)) out.push(`added   ${id}`);
    else if (before.get(id) !== line) {
      const [a, b] = [JSON.parse(before.get(id)!) as AnswerKeyEntry, JSON.parse(line) as AnswerKeyEntry];
      const what = (['prompt', 'promptDetails', 'options', 'answer', 'standard', 'contentVersion'] as const)
        .filter((k) => JSON.stringify(a[k]) !== JSON.stringify(b[k]));
      out.push(`changed ${id} (${what.join(', ')})`);
    }
  }
  for (const id of before.keys()) if (!after.has(id)) out.push(`removed ${id}`);
  return out;
}
```

```ts
      studentName: 'Noor',
      grade: 3,
      checkupSkipped: true,

        kind: 'practice',
        quizId: 'e2e-number-line',
        title: 'Number line',
        refs: [{ kind: 'generated', templateId: 'g3.nf2.fraction-on-a-number-line', seed: 4, origin: 'new' }],
        answers: {},
        flagged: {},
        currentIndex: 0,
        startedAt: '2026-01-01T00:00:00.000Z',
        secondsElapsed: 0,
      },
    });
    await page.goto('./');
    await page.getByRole('button', { name: UI.continue }).click();

    const picture = page.getByTestId('prompt-details');
    await expect(picture).toBeVisible();

    const measured = await picture.evaluate((el) => {
      const node = [...el.childNodes].find((n) => n.nodeType === Node.TEXT_NODE) as Text;
      const lines = (node.textContent ?? '').split('\n');
      const tickLineStart = lines[0].length + 1;
      const markerLineStart = tickLineStart + lines[1].length + 1;
      const column = lines[2].indexOf('P');
      const left = (offset: number): number => {
        const range = document.createRange();
        range.setStart(node, offset);
        range.setEnd(node, offset + 1);
        return range.getBoundingClientRect().left;
      };
      const style = getComputedStyle(el);
      return {
        column,
        tickUnderP: lines[1][column],
        tickLeft: left(tickLineStart + column),
        markerLeft: left(markerLineStart + column),
        fontFamily: style.fontFamily,
        whiteSpace: style.whiteSpace,
        clientWidth: el.clientWidth,
        scrollWidth: el.scrollWidth,
      };
    });

    expect(measured.whiteSpace, 'a diagram must keep its spaces').toMatch(/^pre/);
```

```yaml
  # Runs after the new build is live. It cannot undo a deploy; a red run here means
  # "the published site is broken, look now".
  smoke:
    needs: deploy
    runs-on: ubuntu-latest
    timeout-minutes: 15
    env:
      SITE_URL: https://frictionlesscode.github.io/ncmathssa/
    steps:
      - uses: actions/checkout@v4
        with:
          # The commit CI passed and that was just deployed, so the tests match the site.
          ref: ${{ github.event.workflow_run.head_sha }}
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
      - run: npm ci
      - name: Install the browser
        run: npx playwright install --with-deps chromium
      - name: Wait for the site to answer
        run: |
          for attempt in $(seq 1 12); do
            if curl --fail --silent --show-error --output /dev/null "$SITE_URL"; then
              echo "Site is up after $attempt attempt(s)."
              exit 0
            fi
            echo "Attempt $attempt: not up yet."
            sleep 10
          done
          echo "The site never answered at $SITE_URL" >&2
          exit 1
      - name: Smoke test the live site
        env:
          E2E_BASE_URL: ${{ env.SITE_URL }}
        run: npx playwright test e2e/01-fresh-visit.spec.ts --project=desktop-chromium --retries=2
      - name: Keep the report when the smoke test fails
        if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: smoke-report
          path: |
            playwright-report/
            test-results/
          retention-days: 14
```

Why each part is there. `ref:` checks out the commit CI passed and the deploy published (`workflow_run.head_sha`), so the test file and the site agree. The polling step exists because Pages can answer 404 for a few seconds after `deploy-pages` returns; it waits up to two minutes, and `--retries=2` covers a stale edge cache. The job cannot undo a deploy; a red run means the published site is broken and someone should look now. The scenario needs no saved data and no secrets.
