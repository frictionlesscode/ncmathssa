## 3. Recommendations
- Extend assertGradeOneReadable to promptDetails and to option text.
- Add a template test asserting that the number named in commonMisconception is one of the option values at every seed (would have caught the oa9 add/subtract mismatch).
- Add a per-tag test re-deriving each distractor value from its tag name (nbt1 side-by-side would fail).
- For authored geometry, flag distractors that are true by subset relation (square is a rectangle, any whole is four fourths).
- Add a prose fact-check for numeric comparisons ("more than five times") and real-world claims (coin sizes).
- Extend the read-back approach of placeValue.testkit to study guides (assert "crosses a hundred" only where the hundreds digit changes).
